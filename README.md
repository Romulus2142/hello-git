## 🚀 Inicio Rápido

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- No requiere instalación de dependencias

### Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/Romulus2142/hello-git.git
cd hello-git
```

2. Abre el archivo en tu navegador:
```bash
# Windows
start src/index.html

# macOS
open src/index.html

# Linux
xdg-open src/index.html
```

O utiliza un servidor local:
```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (si tienes http-server instalado)
http-server src/
```

Luego accede a `http://localhost:8000/src/`

## 🔧 Configuración

### Variables CSS
Edita `:root` en `src/css/main.css` para cambiar colores, fuentes y transiciones:

```css
:root {
    --color-white: #fff;
    --color-black: #000;
    --color-yellow: yellow;
    --font-sans: "Albert Sans", sans-serif;
    --font-serif: "Noto Serif Display", serif;
}
```
